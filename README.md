# Student Marks Calculator 📝

## About the Project
A simple Python project that calculates a student's total marks and average for three subjects.

## Features
- Takes the student's name as input
- Accepts marks for three subjects
- Calculates total marks
- Calculates average marks
- Displays the result

## Technologies Used
- Python

## How to Run
1. Download or clone this repository.
2. Open `student_marks.py` in a Python editor.
3. Run the program and enter the required details.

## Sample Output
- Student: Varsha
- Total marks: 240
- Average: 80.0

## Learning Outcome
Learned Python input, variables, arithmetic operations, and output statements.
